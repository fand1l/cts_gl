# Screenshot placeholders

The README links to four images in this directory. Replace them with your own
captures (PNG, ideally 1280 px wide):

| File | What to show |
|---|---|
| `screenshot-gesture.png` | The diagonal shake, e.g. an arrow overlay on the desktop |
| `screenshot-overlay.png` | The dimmed frozen screen with a selection rectangle |
| `screenshot-settings.png` | The settings dialog, Detection tab |
| `screenshot-result.png` | The Google Lens result page in the browser |

Take them with Spectacle (`spectacle -r`) — the overlay itself can be captured
with a delay: `spectacle -f -d 3000` and then trigger Circle to Search.
